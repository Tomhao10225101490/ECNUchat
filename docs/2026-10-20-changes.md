# 2026-10-20 功能改动说明

本次改动集中在桌面端聊天体验与本地隐私控制，密码协议本身（X3DH、混合 PQXDH、双棘轮）没有改变。所有私密等级和保存动作都由客户端处理，服务器只看到密文。

## 1. 会话私密等级

- 新建私聊时可以选择「普通」或「私密」，每个聊天线程独立保存等级。
- 两种等级都使用同一套端到端加密，区别只在媒体是否允许保存。
- 等级随加密消息内层 JSON 一起发给对方，双方自动同步；服务器无法得知等级。
- 私密会话不显示媒体保存按钮，服务端也无法代替客户端保存。

代码位置：`src/client.py` 的 `create_thread`、`send_text`、`_send_one`、`_on_envelope`。

## 2. 图片/视频的加密缓存与保存

- 收到的图片/视频默认不落明文盘，只保留发送方产生的加密分片缓存。
- 图片预览在内存中解密，不写文件；视频播放时才生成临时明文文件，关闭播放器后删除。
- 「保存」调用系统文件对话框，由用户选择目录和文件名。
- 保存不会修改聊天历史，因此同一个媒体可以反复另存到不同位置。
- 修复了发送方上传后误删密文缓存、导致「媒体密文缺失」的问题。
- 界面不再显示「未保存」字样。

代码位置：`src/attachments.py`、`src/client.py` 的 `media_plaintext`、`save_attachment`，`src/gui/chat_view.py`、`src/gui/main_window.py`。

## 3. 同一好友的多个聊天线程

- 每次「新建消息」选择同一好友，会创建一个新的聊天线程，显示为 `bob`、`bob · 2` 等。
- 点击联系人打开该好友最近的线程，不再直接发起新聊天。
- 新线程创建后通过加密的 `thread_init` 控制消息通知对方；即使不发送正文，对方也能立即在会话列表看到该聊天。
- 联系人列表只显示好友和群聊；陌生人必须通过搜索并添加好友后才会出现。
- 联系人条目右键提供「发消息 / 删除好友 / 拉黑」。

代码位置：`src/store.py` 的 `threads` 表，`src/client.py` 的 `split_dm_conv`、`create_thread`、`announce_thread`，`src/gui/main_window.py`、`src/gui/engine_worker.py`、`src/gui/people.py`。

## 4. 界面修复与临时下线项

- 修复「新建群组」弹窗背景透黑的问题（样式表中 `QDialog` 背景被通用透明样式覆盖）。
- 字母索引栏在字母少于 4 个时隐藏，避免悬浮字母。
- 暂时移除隐私设置中的「朋友圈可见时间」下拉框；后端字段保留默认值，后续再实现。

## 5. 测试与本地数据

- 新增 `tests/test_privacy.py` 覆盖加密缓存、另存为、重复保存、私密等级限制。
- Windows 上 PySide6 测试进程退出会崩溃，`tests/conftest.py` 默认跳过 GUI 测试，普通 `pytest` 不再弹出系统崩溃窗口；设置 `ECNUCHAT_RUN_GUI_TESTS=1` 可显式运行 GUI 测试。
- 当前验证结果：`70 passed, 11 skipped`。
- 验证过程中清空过本地服务器库、客户端库和附件缓存；这些是本地运行数据，不属于代码改动。

## 6. 已知边界

- 修复前已经发送、且密文缓存被删除的旧媒体无法再次保存；新发送的媒体不受影响。
- 私密等级对服务器不可见，但服务器仍能看到信封的收发件人、文件大小等既有元数据。
- 朋友圈可见时间功能仅从设置界面移除，后端的 `moments_visibility` 字段仍然存在。
